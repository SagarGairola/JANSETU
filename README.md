# JANSETU

### From Government Schemes to Application Readiness
### 🚀 Live Demo

[Open JANSETU](https://jansetu-xi.vercel.app)
JANSETU is a citizen-focused government-scheme guidance platform that helps users move from describing a real-world need to understanding relevant government support, eligibility conditions, missing requirements, and the next actionable step.

## The Problem

Citizens may know what they need but often struggle to:

- Identify relevant government schemes or support
- Understand complicated eligibility conditions
- Know which information or documents are missing
- Understand why a requirement may block progress
- Know what to do next or where to apply

Finding a scheme is only the beginning.

## Our Solution

JANSETU lets citizens describe their need in natural language.

The system then:

1. Understands the user's need
2. Extracts relevant context
3. Identifies potentially relevant support
4. Checks published eligibility conditions
5. Distinguishes eligibility from application readiness
6. Identifies missing information and documents
7. Explains blockers
8. Provides the next actionable step
9. Directs the user toward the appropriate official application channel

## Application Readiness Engine

JANSETU focuses on the gap between:

**"I may be eligible."**

and

**"I am ready to apply."**

The Application Readiness Engine connects:

Need → Relevant Support → Eligibility → Readiness → Blocker → Missing Item → Next Action

## Key Features

- Natural-language need understanding
- Context-aware relevance matching
- Targeted clarification questions
- Evidence-aware eligibility reasoning
- Eligibility vs. application-readiness distinction
- Missing information vs. missing documents
- Blocker resolution
- Relevant alternatives where appropriate
- Clear next-action guidance
- Official application-channel guidance

## Current Prototype

The current prototype contains:

- React
- TypeScript
- Vite
- React Router
- React Context API
- Modular TypeScript decision engines
- Provider abstraction
- Evidence-aware eligibility logic
- Application Readiness Engine
- 12 curated scheme records
- Responsive interface

The prototype currently uses a curated local scheme layer. The architecture is designed to support broader verified government sources in future versions.
